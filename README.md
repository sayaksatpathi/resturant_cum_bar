## Overview

A single-page marketing site for a restaurant-and-bar on a deep `#0D0D0D` palette, designed to set a mood and drive reservations. It carries the visitor from an atmospheric hero through the story, menu, signature features, and gallery, then into testimonials and contact — with a pre-filled WhatsApp reservation chat built in.

## ✨ Highlights

- 🌙 **Dark-luxe aesthetic** tuned for food & nightlife branding
- 📖 **About + Menu + Features** sections that tell the venue's story
- 📸 **Gallery & testimonials** for atmosphere and social proof
- 📅 **WhatsApp reservation chat** pre-loaded with a booking message
- 📐 **Fully responsive**, smooth-scrolling single page

## 🧱 Tech Stack

- **React 18 + TypeScript** on **Vite**
- **Tailwind-style utility CSS** with MUI + Radix UI primitives

## 🚀 Getting Started

```bash
npm install     # install dependencies
npm run dev     # start the dev server
npm run build   # production build
```

## 🗂️ Structure

```
src/app/
├── components/   # Navigation, Hero, About, Menu, Features, Gallery,
│                 # Testimonials, Contact, Footer, WhatsAppChat
└── App.tsx       # composes the page + reservation chat
```
